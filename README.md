              ТЗ
  --------------------------------------------------------
  Название: LitMate - your book buddy  

  cause books connect us
  
  Цель проекта: создать современный и удобный сайт библиотеку, в котором реализованы поиск, фильтры,
  избранное и возможность сохранять цитаты; добавить чтение книг и попробовать добавить аудио-книги,
  также их прослушивание; создать приятный интерфейс и добавить возможность смены темы (светлая-темная)

  Основной функционал:
  
      1. Главная страница 
         -сверху будет расположен аккаунт, разделы избранное, популярное, жанры, новое, аудиокниги;
         -при нажатии на раздел ИЗБРАННОЕ перехд на другую страницу, где сохранены избранные книги,
          также раздел с "Цитатами из книг", нажимая туда тоже переход на другую страницу;
         -при нажатии на разделы популярное, жанры, новое, аудиокниги страница скроллится до определенного блока
         на странице;
         -блок "продолжить чтение"
         -ниже разделы популярное, жанры, новое, аудиокниги каждый небольшого размера, можно листать книги в ряд и после какого-
         то количества можно увидеть кнопку "Посмотреть больше", либо же нажать на название раздела и тебя перебросит на другую страницу,
         конкретно под этот раздел;

      2. Работа с книгами
        -поиск по названию, автору
        -фильтр по алфавиту(с начала и с конца)
        -фильтр по формату (текст/аудио)

      3. Избранное и цитаты
       -отдельная страница с избранными книгами
       -подраздел "сохраненные цитаты", которые можно сохранять из книг

      4. Чтение и аудио
       -можно открыть книгу в режиме чтения (апи)
       -можно прослушать аудио-книгу (апи)
       -сохраняется прогресс при чтении/прослушивании

      5. Тема
       -можно менять тему светлая/темная
